# NEXUS-M — Power BI Executive Analytics

## Overview

NEXUS-M (Autonomous Merchant & Network Intelligence Platform) is a synthetic payment-network analytics project designed to monitor transaction performance, investigate failures, identify business opportunities, and track settlement reconciliation.

Power BI provides the business intelligence layer for exploring the outputs generated by the Python analytics pipeline.

**Important:** All business data is synthetic and intended for demonstration and portfolio purposes.

## Project Structure

* `data/` — exported datasets for Power BI.
* `documentation/data_dictionary.md` — dataset and field documentation.
* `../../analytics/bi/export.py` — script that exports analytical outputs for reporting.

## Export Power BI Data

From the project root, activate the virtual environment and run:

```powershell
python -m analytics.bi.export
```

The exporter collects available outputs from the project's processed-data directories and writes them to `dashboards/powerbi/data/`.

Ensure that the relevant analytics phases have run before exporting.

## Executive Command Center

Create a Power BI report page named **Executive Command Center** with the following layout:

1. Header: NEXUS-M EXECUTIVE COMMAND CENTER.
2. Four KPI cards:

   * Transaction Count
   * Transaction Value
   * Success Rate
   * Failure Rate
3. Transaction Volume / Success Rate Trend.
4. Partner Performance.
5. Regional Performance.
6. Top Opportunities.
7. Reconciliation Health.

Use actual dataset values and measures. Do not use example values as real results.

## Data and Metric Notes

* Success and failure rates should use consistent transaction-status definitions.
* Transaction value should use the currency represented by the underlying data.
* Estimated recoverable value is a scenario-based estimate, not guaranteed revenue.
* Transaction value affected by a reconciliation exception is not necessarily a financial loss.
* Report missing datasets or unavailable metrics rather than inventing values.
